## 2. プロダクト名・サービス名の商標リスク監査

### 2.1 現在の名称
- **アプリケーション名**: "todo-app"
- **API名**: "Todo API"
- **パッケージ名**: "todo-app"

### 2.2 商標リスク評価

#### 🔴 高リスク事項
1. **"Todo"の使用**
   - 一般的な英単語として広く使用されているが、アプリケーション分野での商標登録が多数存在
   - Microsoft、Google、Apple等の大手企業が類似サービスを提供
   - 商標権侵害のリスクが存在

#### 🟡 中リスク事項
1. **"Todo API"の組み合わせ**
   - API分野での商標登録は少ないが、サービス名として使用する場合はリスクあり

### 2.3 代替案提示

#### 推奨代替名
1. **TaskFlow** - タスク管理の流れを表現
2. **DoNext** - 次にやることを示唆
3. **TaskMaster** - タスク管理の専門性を表現
4. **QuickTask** - 迅速なタスク処理を表現
5. **MyTaskHub** - 個人のタスク中心地を表現

### 7.2 自動ライセンスチェックの設定

#### GitHub Actions設定例
```yaml
name: License Check
on: [push, pull_request]
jobs:
  license-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Check licenses
        run: |
          npx license-checker --onlyAllow 'MIT;Apache-2.0;BSD-2-Clause;BSD-3-Clause;ISC'
          pip-licenses --allow-only 'MIT;Apache-2.0;BSD-2-Clause;BSD-3-Clause'
```
